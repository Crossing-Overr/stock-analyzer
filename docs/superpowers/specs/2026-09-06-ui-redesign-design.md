# Редизайн интерфейса — «тёмный финтех»

**Дата:** 2026-09-06
**Статус:** утверждён владельцем (мокап согласован), готов к плану реализации

## Цель

Причесать интерфейс: сделать современнее и понятнее. Главная проблема сейчас —
**главный вывод не виден без скролла**: пользователь листает ~20 одинаковых
плиток с метриками и только потом доходит до DCF, ради которого и пришёл.

Владелец выбрал направление **B — тёмный финтех** (вариант «терминал» отклонён,
светлая тема отклонена). Мокап «сейчас vs предлагаю» согласован.

## Принципы

1. **Вывод вперёд.** Сразу под хедером — карточка-вердикт: дорого или дёшево.
2. **Иерархия вместо стены.** Ключевое крупно, второстепенное — компактными
   строками и в сворачиваемых блоках.
3. **Мягкие поверхности.** Глубокий фон, поверхности без жёстких рамок, крупные
   радиусы, больше воздуха.
4. **Цвет только по смыслу.** Акцент — индиго/фиолетовый; зелёный/красный только
   для оценок и изменений.

## Палитра (токены)

Уходим с Catppuccin на более мягкую финтех-палитру. Все цвета — **единый
источник в `ui/theme.py`**; сейчас они захардкожены ещё и в `ui/components.py`
(`_PLOT_BG`, `_GRID`, `_AXIS`, `_SCENARIO_META`) и в `pages/4_💎_Идеи.py`.

| Токен | Значение | Назначение |
|---|---|---|
| `bg` | `#0f1116` | фон страницы |
| `surface` | `#16181f` | карточки |
| `elevated` | `#1c1f28` | вложенные элементы, полосы |
| `border` | `#242833` | границы |
| `text` | `#f4f4f5` | основной текст |
| `text_dim` | `#a1a1aa` | вторичный |
| `text_muted` | `#71717a` | подписи |
| `accent` / `accent2` | `#6366f1` / `#8b5cf6` | акцент, градиент |
| `pos` / `neg` / `warn` | `#22c55e` / `#ef4444` / `#f59e0b` | рост / падение / риск |

Сценарии: bear `neg`, base `accent`, bull `pos`.

`.streamlit/config.toml` обновляется в тон (`backgroundColor`,
`secondaryBackgroundColor`, `textColor`, `primaryColor`).

## Вкладка «Анализ» — новая раскладка

Порядок сверху вниз:

1. **Хедер**: аватар тикера (первая буква на градиенте), название, `AAPL ·
   Сектор`, справа — цена и дневное изменение цветом.
2. **Карточка-вердикт** (главное новое):
   - Бейдж **НЕДООЦЕНЕНА / СПРАВЕДЛИВО / ПЕРЕОЦЕНЕНА** (пороги: апсайд > +15%
     → недооценена; от −15% до +15% → справедливо; < −15% → переоценена).
     Фон карточки — мягкий градиент в цвет вердикта.
   - Справедливая цена (Base) крупно + апсайд рядом.
   - **Шкала bear/base/bull относительно рыночной цены**: горизонтальная полоса,
     засечки трёх сценариев и маркер рынка, подписи снизу.
   - Строка условий: `DCF · Base · WACC 10.1%`.
   - Если DCF неприменим (FCF ≤ 0) — вместо вердикта нейтральная карточка с
     объяснением (как сейчас, но в новом стиле).
3. **Две карточки реверс-DCF**: «Заложено в цену» и «Ожидаемая доходность»
   (сейчас есть, перекрашиваются; в подписи доходности — живая ставка 10-леток
   вместо константы «≈ 4%»).
4. **График цены** за год.
5. **Ключевые метрики компактными строками** (P/E · Fwd P/E, EV/EBITDA, чистая
   маржа, ROE) — вместо восьми плиток.
6. **Сворачиваемые блоки**: «Все мультипликаторы», «Финансы (TTM)»,
   «О компании», «Структура стоимости и чувствительность» (waterfall, график
   справедливой цены, сетка), «История финансов».

Карточки трёх сценариев (bear/base/bull) остаются, но переезжают внутрь блока
«Структура стоимости» — наверху их роль берёт вердикт.

## Остальные вкладки

Логика не меняется, только перекраска под новые токены:

- **Сравнение** — таблица на новых цветах, подсветка best/worst в `pos`/`neg`.
- **Избранное** — строки в стиле карточек.
- **Идеи** — карточки уже близки к целевому стилю; заменяем захардкоженные
  цвета на токены, бейдж риска — `warn`.
- **Графики** (`ui/components.py`) — фон/сетка/оси из токенов, линии в `accent`.

## Что НЕ меняется

- Вся расчётная логика (`core/`) — ни одной формулы.
- Состав данных и метрик — ничего не выкидываем, только перегруппировываем.
- Дисклеймеры остаются.

## Архитектура

- `ui/theme.py` — единственный источник цветов: словарь токенов `COLORS`,
  генерация CSS из него, экспорт для Python-кода (графики, инлайн-HTML).
- `ui/components.py` — берёт цвета из `theme`, больше не держит свои константы.
  Пополняется: `verdict_card(...)`, `scenario_scale(...)`, `metric_rows(...)`,
  `ticker_header(...)`.
- `pages/1_📊_Анализ.py` — пересобирается по новому порядку; расчёты те же.
- `pages/2,3,4` — точечная замена цветов на токены.

## Тестирование

- Логика не трогается → существующие **85 тестов должны остаться зелёными**.
- Новый чистый хелпер `verdict_for(upside)` (бейдж по порогам ±15%) —
  покрывается юнит-тестами: недооценена / справедливо / переоценена / None.
- Все 4 страницы проверяются через AppTest на отсутствие исключений.
- Визуальная проверка в браузере: Анализ (AAPL — переоценена, INTC — DCF
  неприменим), Идеи, Сравнение, Избранное.

## Краевые случаи

- **DCF неприменим** (INTC, банки) → нейтральная карточка вместо вердикта,
  шкала не рисуется.
- **Апсайд None** (справедливая ≤ 0, напр. AMZN с SBC) → «не определяется»,
  бейджа нет.
- Длинные названия компаний обрезаются, вёрстка не ломается.

## Дисклеймер

Без изменений: только для образовательных целей, не инвестиционная рекомендация.
