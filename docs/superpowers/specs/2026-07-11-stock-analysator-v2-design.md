# Stock Analysator v2 — дизайн

**Дата:** 2026-07-11
**Статус:** утверждён владельцем, готов к плану реализации

## Цель

Развить текущее приложение (один файл `app.py`, Streamlit + yfinance) до более
«продвинутой» и портфолио-пригодной версии, закрыв требования владельца:

1. Ввод тикера → три прогноза (DCF Bear/Base/Bull) + основные метрики + график роста.
2. Сравнение нескольких тикеров.
3. Основная информация о компании (описание, можно на английском).
4. Избранное (портфолио — опционально, позже).
5. Публичная внешняя ссылка, которую может открыть кто угодно; Избранное при этом
   локальное (у каждого посетителя своё).

## Выбранный путь

**Путь A — остаёмся на Streamlit.** Разбиваем монолит на модули, добавляем
кэширование, делаем multipage-вкладки, деплоим на Streamlit Community Cloud
(бесплатный публичный URL). Избранное — в `localStorage` браузера.

Отклонённые альтернативы:
- **B. FastAPI + React** — максимально кастомно и «портфолийно», но много работы;
  владелец не разработчик. Отложено на будущее, когда содержание устаканится.
- **C. Гибрид** (Python-библиотека + Streamlit сейчас, React потом) — преждевременно.

Данные: только `yfinance` + кэш на старте. Второй источник (Financial Modeling
Prep) — потенциальный фолбэк на будущее, сейчас не делаем (лишний API-ключ).

## Слой данных + кэш

`core/data.py` — единая точка загрузки.

```python
@st.cache_data(ttl=900)   # 15 минут
def load_ticker(symbol: str) -> TickerData | None:
    tk = yf.Ticker(symbol)
    ...  # info, history, financials, balance, cashflow
    return TickerData(...)   # dataclass с уже вынутыми и очищенными полями
```

- Кэш на 15 минут: повторный ввод того же тикера и пересечения тикеров в
  Сравнении не дёргают Yahoo заново — быстрее и меньше шансов на rate-limit.
- Возвращаем свой `TickerData` (dataclass), а не сырой `info`. UI не знает про
  yfinance — смена источника в будущем не трогает UI.
- `safe()`-хелперы и форматтеры (`fmt_large`, `fmt_pct`, `fmt_mult`) переезжают сюда.
- Тикер не найден / нет данных → `None`; вкладка показывает аккуратное сообщение.

## Вкладки

### 📊 Анализ
Текущий экран без потери функций:
- Хедер компании; цена + дневное изменение; кап-я / EV / 52w High/Low.
- График цены за год.
- 8 мультипликаторов; финансы TTM; «О компании» (описание из Yahoo, англ.).
- DCF — три сценария (Bear/Base/Bull) со слайдерами: карточки `старт% → конец%`,
  апсайд, доля терминальной стоимости, предупреждение при TV > 75 %, waterfall
  «структура стоимости (Base)» и «справедливая цена vs текущая».
- Кнопка ⭐ «В избранное» рядом с тикером.

### ⚖️ Сравнение
Ввод нескольких тикеров (`AAPL, MSFT, NVDA`) или подтягивание из Избранного:
- Таблица: **тикеры в столбцах, метрики в строках** — цена, кап-я, P/E, Fwd P/E,
  P/S, EV/EBITDA, маржи, ROE, рост выручки, див. доходность.
- Отдельная строка «Апсайд (Base DCF)» — Base-сценарий для каждого тикера по
  текущим слайдерам DCF.
- Лучшие/худшие значения в строке подсвечиваются цветом (зелёный/красный).

### ⭐ Избранное
Тикеры из `localStorage`:
- Список сохранённых с мини-строкой (цена, дневное изменение, апсайд Base).
- Клик → открыть во вкладке Анализ. Кнопка удалить.
- Кнопка «сравнить все» → передаёт список во вкладку Сравнение.

## Избранное (технически)

- Компонент `streamlit-local-storage` (одна зависимость) хранит список тикеров в
  браузере посетителя.
- `core/favorites.py` даёт `get_favorites()`, `add(symbol)`, `remove(symbol)` —
  вкладки не знают про детали хранения.
- У каждого посетителя публичной ссылки — своё избранное, без логина. Локально —
  то же самое (браузер владельца).

## Деплой

- Локальный запуск (`streamlit run app.py`) продолжает работать — тот же код.
- Каждый `git push` обновляет и локально, и в вебе.
- Требование: инициализировать git-репозиторий (сейчас проект не под git).
  Владелец не разработчик — все шаги дать командами.
